# 🌊 大鱼吃小鱼 - 海洋王者争霸赛

一款基于 HTML5 Canvas + Node.js 开发的经典大鱼吃小鱼游戏，具有完整的前后端分离架构和丰富的游戏玩法。

---

## 🎮 游戏特色

### 🌊 海洋氛围界面
- 深邃的海洋主题设计，沉浸式游戏体验
- 渐变蓝色背景，模拟深海环境
- 动态气泡效果，增添海洋气息

### 🎯 三种游戏模式
| 模式 | 难度 | 榜单名称 | 主题颜色 |
|------|------|----------|----------|
| 简单 | 入门 | 人榜 | 🟡 黄色 |
| 正常 | 进阶 | 地榜 | 🟣 紫色 |
| 困难 | 挑战 | 天榜 | 🔴 红色 |

### 📈 等级成长系统
- **鱼类进化**：7级鱼进化系统（LV1 ~ LV7）
  - LV1 小蝌蚪 → LV2 草鱼 → LV3 金鱼 → LV4 鲤鱼 → LV5 鲨鱼 → LV6 鲸鲨 → LV7 巨鲸
- **玩家等级**：完整的 LV1-100 等级体系
  - 每10000积分升一级

### 🏆 称号系统
| 等级区间 | 称号 |
|----------|------|
| LV1-10 | 鱼卒 |
| LV11-20 | 鱼士 |
| LV21-30 | 鱼师 |
| LV31-40 | 鱼尊 |
| LV41-50 | 鱼宗 |
| LV51-60 | 鱼王 |
| LV61-70 | 鱼帝 |
| LV71-80 | 鱼圣 |
| LV81-90 | 鱼斗罗 |
| LV91+ | 封号斗罗（自定义称号） |

### 👑 海洋王者排行榜
- **人榜**：简单模式最高分排行（黄色主题）
- **地榜**：正常模式最高分排行（紫色主题）
- **天榜**：困难模式最高分排行（红色主题）
- 管理员「海神」直接显示在三大榜单首位

### 🔧 管理功能
- **海神赐福**：管理员可提升玩家等级
- **神罚**：管理员可降低玩家等级
- 用户管理：查看所有用户信息
- 游戏记录管理：查看所有游戏记录

## 🚀 快速开始

### 本地开发

```bash
# 启动后端服务
cd backend
npm install
node server.js

# 启动前端服务（另一个终端）
cd frontend
python -m http.server 5500
```

打开浏览器访问 `http://localhost:5500` 即可开始游戏！

## 🎯 游戏玩法

### 操作方式
- **鼠标控制**：移动鼠标控制鱼的游动方向
- **键盘控制**：WASD 或方向键控制移动

### 游戏规则
1. 吃掉比自己等级低的鱼来获得经验
2. 躲避比自己等级高的鱼
3. 可以吃掉同等级的鱼
4. 被大鱼吃掉游戏结束
5. 游戏时间越长，分数越高

### 游戏模式差异
- **简单模式**：小鱼不会逃跑，适合新手
- **正常模式**：小鱼会短暂加速逃跑
- **困难模式**：小鱼持续逃跑，大鱼生成更快

## ☁️ 部署说明

### 后端部署（Railway）

1. 确保项目根目录有 `package.json`：
```json
{
  "scripts": {
    "start": "cd backend && npm install && node server.js"
  }
}
```

2. 后端端口支持环境变量：
```javascript
const PORT = process.env.PORT || 3000;
```

3. 配置 Railway 自动部署：
   - 连接 GitHub 仓库
   - 设置 Root Directory 为 `backend`（或使用根目录 package.json）
   - 自动读取环境变量 PORT

### 前端部署（GitHub Pages）

1. 将前端代码推送到 GitHub
2. 在仓库 Settings 中开启 GitHub Pages
3. 设置 Source 为 `main` 分支，路径为 `/frontend`
